# 双阳极等离子喷涂智能工艺设计平台（傻瓜式 V1.6）

## V1.6 更新了什么（2026-09）

1. **首页智能操作区**：打开平台即可「拖入 Excel → 点智能分析」，两步拿到分析摘要卡；
   摘要卡每条结论旁有证据徽标，点开可看数值、计算方式与数据/模型版本。
2. **全程可溯源**：每个分析 run 自动生成 `evidence_manifest.json`（证据清单）与
   `summary.json`，并随结果 ZIP 一起打包——论文/组会用到的每个数字都能查到出处。
3. **反套话**：所有自动结论都由「真实计算值拼出来」，数据不够时明确说
   「当前数据不足以支持该判断」，绝不输出空话。
4. **论文级图表**：网页图与论文导出图统一为 Nature 期刊配色与版式
   （单栏 89mm / 双栏 183mm），每张图带样本数、交叉验证方式注脚；
   Demo 数据自动加水印。
5. **更清爽的界面**：每个页面按「导语 → 主证据 → 次级证据 → 操作」四段式重组，
   常用操作在明面，细节收进折叠区。

其余 13 项功能全部保留，详见 `docs/RELEASE_V1.6.md`。

## 你只需要做 3 件事

### 第一次使用（macOS）
1. 解压整个文件夹；
2. 双击 `01_首次安装.command`；
3. 安装完成后双击 `02_启动平台.command`。

浏览器会自动打开平台。

### 第一次使用（Windows）
1. 解压整个文件夹；
2. 双击 `01_首次安装_Windows.bat`（需已安装 Python 3.11+，安装时勾选 Add to PATH）；
3. 安装完成后双击 `02_启动平台_Windows.bat`，浏览器打开 http://localhost:8501。

Windows 使用项目内独立 `.venv`（`.venv\Scripts\`），与 macOS 完全独立，互不复制。
若 xgboost 报 libxgboost.dll / OpenMP 错误，安装
[VC++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) 后重试。

### 环境自检（可选，两个系统通用）
```
python scripts/platform_check.py
```
自动检查操作系统、Python 版本、虚拟环境和关键依赖。

> 如果 macOS 提示“无法打开”，右键该 `.command` 文件 → 打开 → 再确认一次。

## 平台的研究逻辑

双阳极结构/工艺参数  
→ 射流与粒子状态  
→ 涂层缺陷网络  
→ 涂层性能  
→ 多目标逆向设计

### Stage 1：过程代理模型
输入：喷枪结构 + 工艺参数  
输出：电压、射流温度/速度、粒子温度/速度  
模型：XGBoost  
训练：按 `batch_id` 分组交叉验证 + OOF

### Stage 2：缺陷网络代理模型
输入：工艺参数 + Stage 1 OOF 过程状态  
输出：孔隙率、层间未结合、未熔颗粒、裂纹密度、缺陷连通度  
模型：XGBoost  
训练：继续采用 OOF，避免信息泄漏

### Stage 3：性能代理模型
输入：工艺参数 + 预测过程状态 + 预测缺陷网络  
输出：结合强度、硬度、磨损、腐蚀、空蚀、耦合损伤、沉积效率  
模型：小/中数据优先 Gaussian Process；数据较大时自动使用 Random Forest  
可输出预测不确定性

### Stage 4：逆向工艺设计
目标默认：
- 孔隙率最小
- 结合强度最大
- 耦合损伤最小

工程约束默认：
- 沉积效率 ≥ 45%
- 送粉速率 ≥ 15 g/min

输出不是单一“最佳点”，而是一组 Pareto 最优工艺窗口。

## 没有真实数据时怎么用

直接打开平台，保持左侧：
`使用 DEMO 模拟数据 = 开`

最快路径（V1.6 智能一键）：
1. 首页「智能操作区」→ 展开拖放区；
2. 把 `data/demo/DEMO_双阳极喷涂数据.xlsx` 拖进去；
3. 点「🚀 智能分析」；
4. 等进度条走完，直接看摘要卡（每个数字都有证据徽标可溯源）。

传统路径（与 V1.5 相同）：
1. `③ 一键训练`
2. `🚀 开始训练`
3. `④ 单点预测`
4. 输入一组参数并预测
5. `⑥ 逆向优化`
6. `🧭 开始逆向寻优`

内置 Demo 数据只用于验证程序能不能跑通，不能用于科研结论。

## 有真实数据以后怎么用

模板位置：

`data/template/真实数据录入模板.xlsx`

只填写 `Experiments` 工作表。

原则：
- 不要修改表头；
- 每一行 = 一个样品/实验条件；
- `experiment_id` 唯一；
- 同一喷涂批次用相同 `batch_id`；
- 没测的数据可以先留空；
- 结构参数即使固定，也建议记录。

然后：
1. 启动平台；
2. 左侧关闭 `使用 DEMO 模拟数据`；
3. 首页「智能操作区」直接拖入 Excel → 点「智能分析」（推荐，会自动完成
   检查→训练→解释→洞察→结果包全流程）；或按传统路径走：
   `② 数据导入` 上传 Excel → 查看质量检查 → `③ 一键训练` → 点训练。

## 缺陷网络为什么单独一层

本项目不是简单做“工艺参数 → 性能”的黑箱预测。

希望建立：
`工艺 → 热/力过程状态 → 缺陷形成 → 服役性能`

因此将以下指标作为中介层：
- porosity_pct
- lamellar_gap_pct
- unmelted_particle_pct
- crack_density_mm_mm2
- defect_connectivity_index

其中 `defect_connectivity_index` 建议后续结合截面图像分析、三维 CT 或连通孔/裂纹统计重新定义，V1 仅保留接口。

## 推荐的数据积累节奏

### 0–30 组
先保证数据记录标准化，不追求模型结论。

### 30–60 组
可以开始看过程代理模型和变量敏感性，但只作为趋势探索。

### 60–120 组
开始进行分组交叉验证、SHAP、缺陷网络关联和初步 Pareto 优化。

### 120 组以上
视重复性和变量覆盖情况逐步开展主动学习、贝叶斯优化、跨喷枪结构建模。

这不是硬性样本数门槛；真正有效样本量还取决于变量数量、重复实验、噪声和参数空间覆盖度。

---

## 最重要的原则

1. 不使用 Demo 数据做科研结论。
2. 同一 batch 不跨训练/验证。
3. 后级模型只吃前级 OOF 预测，不吃“训练集拟合答案”。
4. 所有模型都要保留实验数据版本。
5. 逆向设计给 Pareto 工艺窗口，不随意宣称一个万能最佳点。
6. （V1.6 新增）引用平台产出的任何数字前，先打开旁边的「证据详情」
   确认样本量、CV 方式和数据版本——查得到出处的数字才写进论文。
