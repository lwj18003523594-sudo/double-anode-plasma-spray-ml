# V1.7 发布说明 · 核心价值验证体系（L1→L4）

## 本版本核心

在 V1.6 全部功能不变的基础上，新增**四层核心价值验证体系**——用四类可溯源证据回答
「这个平台到底值不值」：

| 层 | 验证问题 | 模块 | 界面入口 |
|---|---|---|---|
| **L1 不确定度校准** | 模型给出的 σ 是否可信？ | `src/calibration.py` | ③ 模型训练 → L1 校准 |
| **L2 推荐即命中** | 推荐的工艺点做实验能落进预测区间吗？ | `src/validation_tracker.py` | ⑦ 导出任务单 → ⑥ 回灌判定 |
| **L3 闭环效率** | 模型引导比随机试错省几次实验？ | `src/benchmark.py` | ⑥ 数据洞察 → L3 基准 |
| **L4 物理一致性** | 模型规律符合喷涂物理吗？ | `src/physics_check.py` | ⑤ 模型解析 → L4 检验 |
| **总报告** | 通过到哪层、缺什么证据、下一步做什么 | `src/core_value_report.py` | ⑧ 结果输出 → 总报告；首页四层徽标 |

## 各层方法与产物

- **L1**：带 σ 的全链交叉验证（折划分规则与平台全链 CV 完全一致）→ 逐目标 1σ/2σ 覆盖率
  （期望 68%/95%）、z 分数方差、校准因子 k=√(z²)。因子写入 `models/calibration.json`，
  ④ 工艺预测 / ⑦ 逆向设计 / L3 悲观惩罚的 σ 自动乘以该因子（无文件时因子=1，行为同 V1.6）。
  产物：校准曲线（网页交互 + 600dpi PNG）、校准报告 md。实测 demo：7 目标全部
  1σ 覆盖 67.5–71.1%（良好）、k≈0.98–1.03。
- **L2**：Pareto 前沿一键导出「验证任务单」（与平台数据模板同构、REC- 编号、batch_id
  预填版本号）→ 实验回填 → 上传判定 |实测−预测| ≤ k·σ_cal（1σ/2σ 双口径）。
  判定基准为 candidates 存档的校准后预测；σ 不可用或实测缺失如实标「待填写」，不编造。
  判定后自动刷新总报告。任务单可直接在 ② 数据管理并入训练数据。
- **L3**：重放竞赛——初始子集从非达标点抽（「尚未找到好工艺」的公平起点），模型引导
  （悲观惩罚 mean∓κ·σ_cal + 综合最优）vs 随机基线，真实标签全部取自数据集（严禁预测
  冒充真值）。输出节省次数 N（中位数与区间）、对比曲线（网页 + 600dpi PNG）、
  N≤0 时自动给出三项排查（初始样本/规格松紧/κ 强度）。规格为指令集预填
  （孔隙率≤4、结合强度≥55、耦合损伤≤0.6），界面可改。
- **L4**：物理期望表（`config/physics_expectations.yaml`，六条预填、可自定义）×
  两类证据交叉判定：事实行 Spearman 符号 + 模型 PDP 部分依赖 Theil-Sen 稳健斜率符号
  （对 XGBoost/GPR/RF 统一适用）。PASS/WEAK/FAIL/UNVERIFIED 四级；
  FAIL 附原因诊断（范围窄/共线性/过拟合）与针对性补实验建议。
- **总报告**：一页式结论（连续通过到哪层）+ 逐层证据状态 + 自动纠偏建议
  （命中率低→查校准/补稀疏区；覆盖率低→扩数据；无优势→三项排查；FAIL 多→查实现/共线性）。
  缺失层明确写「暂无证据」。

## 已知限制

1. L3 演示数据下模型引导优势不明显（N≈0）——合成数据模型预测能力有限（R² 低），
   属诚实结果；真实数据下模型质量提升后优势会显现。
2. L3 历史版本迭代曲线：历史版本未存训练数据快照，超体积无法回算，报告中如实注明；
   建议自本版本起经 L2 闭环逐步积累。
3. 初始子集构造要求非达标样本 ≥ 初始数（默认 15），否则提示调整。
4. L2 回灌判定依赖 candidates 存档（outputs/validation/candidates_*.csv），
   请勿手工删除该目录。
5. 指令集的「换 RBF+Matern(2.5) 核重训」纠偏不适用：平台 Stage 3 已是
   Matern(ν=1.5)+WhiteKernel GP；校准因子机制已自动修正区间宽度。
