## 一、平台是什么

一句话：**把「双阳极等离子喷涂」的工艺经验变成可计算、可预测、可追溯的数据模型**——输入喷枪结构与工艺参数，输出射流/粒子状态、涂层缺陷与性能预测，并反向推荐最优工艺方案；同时用四层验证体系（V1.7）证明这些预测值得信任。

### 研究主线（平台的科学逻辑）

```
喷枪结构 / 工艺参数 + 材料 / 粉末属性
        ↓ 【Stage 1 · 过程代理模型】
射流温度 / 速度 · 粒子温度 / 速度 · 电弧电压
        ↓ 【Stage 1.5 · 颗粒熔融与沉积（可选，有标签才启用）】
熔融状态 / 铺展状态 / 过热风险
        ↓ 【Stage 2 · 缺陷网络代理模型】
孔隙率 · 层间未结合 · 未熔颗粒 · 裂纹 · 缺陷连通度
        ↓ 【Stage 3 · 涂层性能模型】
结合强度 · 硬度 · 磨损 · 腐蚀 · 空蚀 · 耦合损伤 · 沉积效率
        ↓
多目标逆向设计（Pareto 前沿 → 验证任务单 → 实验闭环）
```

### 核心运行逻辑（三条铁律贯穿全平台）

1. **防泄漏铁律**：训练评价一律用全链分组交叉验证（按 `batch_id` 分组 GroupKFold，同一批次绝不跨训练/验证集；每折内 Stage 1→1.5→2→3 全部重新训练）。Stage 2/3 的输入只吃 Stage 1/1.5 的 **OOF（折外预测）**，绝不吃训练集拟合值。部署模型另用全量数据单独训练。
2. **证据溯源铁律**：平台输出的每个数字都可追——结论句由真实计算值拼接生成，附证据徽标（n / R² / 数据版本 / run_id）；数据不够时明确写「当前数据不足以支持该判断」，绝不编造。每次分析 run 落盘 `evidence_manifest.json` 并随 ZIP 打包。
3. **数据身份铁律**：数据行按 `data_origin` 分级——只有 `experimental / literature / cfd` 参与真实事实统计；`model_prediction / optimization_candidate`（模型自己的预测行）永不自动进入训练集。

### 研究模式隔离（侧边栏最顶部选择）

四种模式的数据、模型、输出**完全隔离**，互不串扰：

| 模式 | 用途 | 数据来源 |
|---|---|---|
| 双阳极等离子喷涂 | 主线研究 | 模拟演示数据（内置）/ 文献数据 / 真实实验数据 |
| 传统大气等离子喷涂（APS） | APS 文献/实验 | 文献 / 真实 |
| 多电极 / 级联等离子喷涂 | 级联枪研究 | 文献 / 真实 |
| 通用文献数据测试 | 任意 Excel/CSV，自选输入输出 | 文献 |

**左侧边栏**（自上而下）：研究模式选择 → 数据来源 → 推荐流程 → 状态摘要（数据版本 / 模型版本 / CV 方式，与 ③⑧ 同源）。

**主页 8 个 Tab**：

| Tab | 名称 | 一句话定位 |
|---|---|---|

| ③ | 模型训练 | 训练三级链模型 + L1 不确定度校准 |

## 三、快速上手：三条路径

### 路径 A · 新手 3 分钟（不动正式模型）

1. 打开平台 → ① 首页 → 把 Excel/CSV **拖进「智能一键导入」**；
2. 点 **「智能分析」**——平台自动识别字段、逐工作表独立运行（说明表自动跳过）；
3. 看摘要卡：各级模型 R²/RMSE、Top 特征、逐条带证据徽标的结论。
   - 结果只存 `runs/quick_analysis/`，**不会覆盖正式模型**；
   - 满意后在运行历史中填 run_id 主动「设为正式模型」。

### 路径 B · 完整科研工作流

**② 数据管理**（上传 → 质量检查 → 文献模式选变量）→ **③ 模型训练**（开始训练 → 看全链 CV 指标 → 运行 L1 校准）→ **④ 工艺预测**（输入参数看三级结果±σ）→ **⑤ 模型解析**（看哪些因素重要 + L4 物理检验）→ **⑦ 逆向设计**（设约束 → Pareto 前沿 → 导出验证任务单）→ **⑥ 回灌实测**（判定推荐命中）→ **⑧ 结果输出**（A–I 图 + 总报告 + ZIP）。

### 路径 C · 核心价值验证流（V1.7 新增）

`③ L1 校准` → `⑦ 导任务单` → 做实验 → `⑥ L2 回灌判定` → `⑥ L3 效率基准` → `⑤ L4 物理检验` → `⑧ 生成总报告`。首页底部四层徽标实时显示通过到哪层。

## 四、逐 Tab 使用说明

### ① 平台首页

- **智能操作区**：智能一键导入（拖放 Excel/CSV）+ 智能分析（三步指示器：导入 → 分析 → 结论；失败会停在当步并如实显示原因）。
- **摘要卡**：Run 信息 → Stage 1/1.5/2/3 各目标 R²/RMSE → Top5 特征重要性 → 逐条可溯源结论 → 下一步指引（run_id 复制）。
- **运行历史**：最近 10 次 Quick Run；「设为正式模型」需主动确认。
- **L1→L4 徽标 + 平台状态面板**：数据量 / 批次数 / 完整率 / 数据版本 / 模型状态（与 ③⑧ 同一数据源，数值必然一致）。

### ② 数据管理

1. **上传数据**（XLSX/XLS/CSV，多 Sheet 自动跳过说明表可选）；
2. **质量检查**：异常字段（hero 区首屏可见）、数据预览、关键字段完整度、重复性统计（n/mean/std/CV%，仅展示不覆盖原始数据）；
3. **文献模式专用**：变量选择（自选哪些列是输入/输出，平台不假设文献都符合完整链条）+ 熔融字段映射（平台只给建议，最终以您确认为准）→ 构建运行时 Schema。
   - 小样本时自动建议 CV 方式（LOOCV / KFold），存在真实批次则优先按批次分组。

### ③ 模型训练

1. 看**数据准备检查**（红色 critical 不通过则无法训练）；
2. 点 **「开始模型训练」**（约 1–3 分钟）：三级链 + 可选熔融层一次完成；训练产物含部署模型、全链 CV 指标、版本记录（`models/history/` 下独立存档，不覆盖旧版本）；
3. 看指标表：Stage 1/1.5/2/3 逐目标 R²/RMSE/MAE（全部为分组 CV 折外值，非训练集拟合值）；R²<0 的弱项会明确提示；
4. **L1 不确定度校准**（V1.7）：点「运行 L1 校准」→ 带σ全链 CV → 逐目标 1σ/2σ 覆盖率（期望 ≈68%/95%）、校准因子 k、校准曲线。
   - **作用**：此后 ④ 预测、⑦ 逆向设计、L3 悲观惩罚中所有 σ 自动乘以 k（无校准文件时 k=1，行为同旧版）。

### ④ 工艺预测

- 输入一组喷枪结构 + 工艺参数（默认值取训练数据中位数，可一键恢复/取中位数）；
- 输出三级全链结果：射流/粒子状态 → 缺陷网络 → **性能 ± σ（已按 L1 因子校准）**；
- 次级证据：训练数据覆盖范围检查（外推预警）+ 最近 5 个真实实验参考。

### ⑤ 模型解析

- 选层级（Stage 1/2）与目标 → XGBoost 特征重要性 Top N（可下载 PNG/CSV）；
- 熔融层分析（启用时）：评价指标、Parity/混淆矩阵、温度比分布（明确标注「非熔融分数」）；
- **L4 物理一致性检验**（V1.7）：点「运行」→ 逐条期望（如「送粉速率↑→孔隙率↑」）给出判定表：
  - 证据A：事实行 Spearman 相关符号；证据B：模型 PDP 稳健斜率符号；
  - **PASS**（双证据一致且符合物理）/ **WEAK**（仅一类）/ **FAIL**（附原因诊断与补实验建议）/ **UNVERIFIED**；
  - 期望表 `config/physics_expectations.yaml` 可自定义增删。

### ⑥ 数据洞察与实验反馈

三源分级洞察（直接观测 / 模型推断 / 优化建议）：
- 数据覆盖、正向实验规律（相关趋势，非因果）、异常复核建议、建议补充实验区域；
- **L2 推荐-验证闭环**（V1.7）：四步流程卡（导出任务单 → 安排实验 → 回填实测 → 上传判定）。
  - 上传填好的任务单 → 自动匹配候选预测 → 逐目标判 |实测−预测| ≤ k·σ_cal → 命中率报告（1σ/2σ 双口径、偏差最大目标、历史趋势）；
  - 判定后**核心价值总报告自动刷新**；
  - 1σ < 60% 时自动给出纠偏建议（查校准 / 补稀疏区 / 收紧悲观惩罚）。
- **L3 闭环效率基准**（V1.7，折叠区）：设目标规格（默认：孔隙率≤4、结合强度≥55、耦合损伤≤0.6，可改）→ 选初始样本/每轮补点/种子数 → 运行重放竞赛。
  - 输出：「达到目标规格，模型引导比随机基线平均节省 N 次实验」+ 对比曲线（均值±σ带）；
  - 真实标签全部取自数据集（重放铁律）；N≤0 或规格过严时自动给出排查建议，不只给数字。

### ⑦ 逆向设计

1. 看目标卡（孔隙率↓ / 结合强度↑ / 耦合损伤↓）与工程约束（沉积效率、送粉下限）；
2. 固定喷枪结构参数（默认训练数据中位数）；
3. 选候选点数量（500–5000）与**搜索域**：训练数据支持域（默认，无外推）/ 设备允许域（探索性，外推点明确标记）；
4. 可选熔融状态约束（默认关闭——平台不假设「熔融越高越好」）；
5. 运行 → Pareto 前沿表（数据支持状态 / 外推风险列）+ 工艺参数范围 + 逐方案推荐依据（次级证据）；
6. **导出验证任务单**（V1.7）：前沿 Top-N 候选生成 Excel——输入参数已预填、状态/缺陷/性能列留空待实验、experiment_id 按 `REC-版本号-序号` 编号（batch_id 预填版本号，并入训练后仍满足分组防泄漏）。候选的校准后预测±σ 同时存档 `outputs/validation/candidates_版本号.csv`（判定基准）。

### ⑧ 结果输出

- 顶部：图表语言（中/英）与格式（PNG/SVG/双出）；
- **核心价值验证总报告**（V1.7）：一键生成 L1→L4 汇总——一页式结论（通过到哪层、缺哪条证据、下一步做什么实验）+ 逐层证据状态表 + 下载；
- **A–I 论文模块**（每个可单独生成，也可一键全套）：
  - A 数据集与变量概况（完整度/分布/相关）
  - B 模型预测性能（指标表 / Parity / Residual / R² 总览）
  - C 模型可解释性（特征重要性）
  - D 全链预测结果
  - E Pareto 优化结果（前沿 + 参数范围）
  - F 预测不确定性
  - G 实验验证（含验证数据模板 Table_G1）
  - H 颗粒熔融与沉积（Stage 1.5 启用时）
  - I 数据洞察 + 证据（Insight_Report / Evidence）
- 图表规范：Nature 版式（单栏 89mm / 双栏 183mm）、600dpi、Times New Roman、统一色板、统计注脚（n/R²/CV 方式）必带；
- **💾 研究快照**：保存当前数据+模型+配置的完整快照；
- **📦 完整科研结果包**：一键 A–I 全套 + 图表科研解读 + 元数据 + evidence_manifest + ZIP。

## 六、科研诚信（平台自动守护的规则）

- 指标全部来自分组 CV 折外预测，**严禁**训练集拟合值冒充评价；
- 温度超熔点 ≠ 完全熔融——平台不用温度阈值造熔融标签；
- 无统计检验不写「显著」；禁「最佳工艺」等绝对化表述（校验脚本自动扫描）；
- 外推预测必须标记；演示数据结论自动加水印；
- L3 竞赛真实标签只来自数据集，严禁模型预测冒充真值；
- L2 缺实测/缺σ的记录如实标「待填写」，不编造判定。

## 七、常见问题

| 问题 | 答案 |
|---|---|
| 智能分析会覆盖我的正式模型吗？ | 不会。Quick Run 只写 `runs/`，设为正式需主动确认。 |
| 训练指标为什么和预测一样好/差？ | 指标是分组 CV 折外值（诚实口径）；部署模型用全量数据另训。 |
| Stage 1.5 没启用？ | 数据缺熔融状态标签（需 ≥20 有效值），主链不受影响。 |
| L3 显示「无法开展竞赛」？ | 当前数据无满足目标规格的样本点——按提示放宽规格或先扩边界实验。 |
| 想回滚版本？ | `git reset --hard v1.6`（V1.6）/ `v1.7`；模型在 `models/history/` 逐版本存档。 |
| Windows 打不开？ | 先跑 `01_首次安装_Windows.bat`（需 Python 3.11+ 勾选 Add to PATH）。 |
| 论文图怎么引用数字？ | 每图带 metadata JSON + 绘图数据 CSV + 注脚（n/CV 方式），ZIP 内可溯源。 |
