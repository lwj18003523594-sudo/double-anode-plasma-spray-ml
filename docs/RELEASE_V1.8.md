# V1.8 发布说明 · 系统优化与验收严谨化（按外部审计方案落实）

依据：《双阳极平台V1.8_系统优化与开发验收方案》（外部审计视角，基于 V1.7 截图与
说明书的 16 项诊断）。本版本按方案 §12 顺序落实 **P0 全部 + P1 全部**，P2 仅做
L4 语义与状态铁律（六页 UI 重组未做——保持 8 Tab + 工作台化，见「已知边界」）。

## 一、P0 · 状态身份与严谨化（方案 §2/§10）

### 1. 全局身份绑定（新模块 `src/status_binding.py`）
- **每个结果自身携带上下文**：calibration.json / L2 validations / L3 结果 / L4 结果 /
  架构对照全部绑定 model_version + dataset_hash（+ 规则版本 / spec）；
- **时效性三级判定**：fresh（当前模型/数据）/ stale（历史结果，界面明示
  「针对模型X/数据Y，不代表当前状态」）/ unknown（V1.7 及更早的旧文件，
  「旧版结果，待重跑核验」）；
- **状态铁律落地**：未知不是 0，未运行不是失败，过期不是通过。

### 2. 已核验属实的界面问题修复
- **n=0 冒充统计**（⑤ 特征重要性注脚）：改为「模型训练时样本量」（fold_info
  真实记录），取不到时如实标「未知」，严禁填 0；
- **无数据仍显示 L4 PASS**：结果不绑定当前配置 → 显示「历史结果」，不计入
  当前通过状态（首页徽标 / 总报告同步）；
- **k=1 与已校准区分**：界面明示「未校准（k=1 仅表示未缩放，不代表不确定度
  已可信）」；L2 判定带校准状态提示。

### 3. L2 双口径拆分（方案 §2：预测准确性与工程达标不混用）
- **口径一 · 区间覆盖**：|实测−预测| ≤ k·σ_cal（1σ/2σ）——预测准确性；
- **口径二 · 工程达标**：实测值是否满足目标规格——工程有效性；
- **联合达标**：同一候选全部目标同时达标（缺测 → 「未完成」，不算通过/失败）；
- 实测验证：demo 回灌显示「区间覆盖 57%（1σ）/100%（2σ）但工程达标 0%」——
  两口径诚实分开，「落进区间但性能不达标」不再被误报为推荐成功。

### 4. 任务单身份分离（方案 §2：模型版本不冒充实验独立性）
- 新增 `recommendation_run_id` 列（推荐轮次身份）；
- **batch_id 不再预填版本号**——留空待实验者填【实际喷涂批次】（使用说明
  明确指引：同一炉/连续喷涂的候选填同一批次号）；
- candidates 存档携带导出时模型/数据版本（冻结预测基线身份）。

## 二、P1 · 双层主链与消融对照（方案 §5）

### 5. 架构消融对照（新模块 `src/architecture_compare.py`，③ 模型训练）
同一外层分组 CV 下公平比较三种代理模型架构：
- **direct 直连基线**：工艺 → 性能（无中介）；
- **two_layer 双层主链**：工艺 → 过程状态（XGB OOF）→ 性能（**课题主线**）；
- **three_chain 缺陷增强链**：既有三级链（V1.7），定位为研究对照；

晋级规则（方案 §5.2 写入报告）：缺陷层须在多数目标稳定降误差才晋级为正式
路径，否则保留为研究支路；**选型分数 ≠ 无偏最终性能**（选型与报告分离声明）。

demo 实测：三级链 7 目标胜 6（缺陷层增益 +0.005~+0.031 全为正）→ 晋级
defect_enhanced——缺陷中介层在当前数据下有稳定增益，三级链价值获消融证据支持。

### 6. 设计预测 vs 诊断预测（方案 §6.2，④ 工艺预测）
- 新增任务类型切换：**设计预测**（默认，只输入喷涂前参数，用于逆向优化）/
  **诊断预测**（可勾选填入实测过程状态，直接进入 Stage 2/3）；
- 诊断口径明确标注「不代表设计预测能力」；实测状态不进入任何训练路径
  （训练输入始终只用 OOF 预测——原有铁律保持）。

## 三、P1 · 语义严谨化（方案 §7/§9）

### 7. L4 → 物理合理性诊断（四级语义）
- 判定词改为 **支持 / 证据不足 / 局部相反 / 超出适用域**（V1.7 的
  PASS/WEAK/FAIL/UNVERIFIED 自动映射）；
- 每条附**适用范围**（x 在当前数据的覆盖区间与 n）；
- **同源证据声明**：Spearman 与模型 PDP 基于同一数据/模型，不构成两组独立
  机理验证（方案 §7 原文落地）；报告改名「物理合理性诊断报告.md」；
- 期望方向定位为「待检验假设，非预写结论」。

### 8. L3 → 离线策略评估（方案 §9）
- 名称与结论措辞改为「离线候选池策略效率」，明确声明非真实闭环记录；
- **未达标不强行填数**：部分种子未达成时，节省次数不填报，改报
  「成功比例」（引导更快达标的种子数/达成种子数）+ 各种子步数明细。

### 9. 总报告 → 四个证据维度（方案 §3：不闯关）
- L1→L4 从「逐级通关」改为**四个独立证据维度**（校准 / 覆盖+达标 /
  离线策略评估 / 物理合理性）；
- 一页式结论改为「当前上下文下有效维度 + 历史结果单列」；
- 首页徽标四态：✓ 有效通过 / 🕘 历史 / △ 已运行未通过 / ○ 未运行。

## 四、P1 · 工作台化（方案 §3，8 Tab 内实现）

### 10. 首页研究工作台
- **下一步指引**：按流程链判定当前阻塞点（数据未加载 / 模型未训练 /
  模型已过期 → 逆向设计），给出具体操作位置；
- **待办徽标**：待回灌候选数（candidates 存档 − 已判定数）、L1 未校准提醒；
- 核心动作区随状态变化。
